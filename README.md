# Облік авто — мобільний проєкт

Безкоштовний застосунок українською мовою для Android та iOS. Без реєстрації, реклами й серверної синхронізації. Дані зберігаються локально на пристрої.

## Що реалізовано
- розрахунок пробігу, міської/трасової витрати та залишку пального;
- формули перенесені з наданої книги Excel `123(1).xlsx`;
- список автомобілів з індивідуальними нормами;
- збереження, перегляд, завантаження та видалення записів історії;
- експорт CSV та резервна копія/відновлення JSON;
- офлайн-кеш для веб/PWA-версії.

## Формули з Excel
- загальний пробіг = кінцевий одометр − початковий;
- місто = загальний пробіг × 60% (частка налаштовується);
- траса = загальний пробіг × 40% (частка налаштовується);
- міська витрата = міські км × норма / 100 × (1 + міське коригування / 100);
- трасова витрата = трасові км × норма / 100 × (1 + трасове коригування / 100);
- залишок = залишок перед виїздом + отримано − витрачено.

## Структура
- `www/` — вебінтерфейс і PWA-файли;
- `capacitor.config.json` — конфігурація Capacitor;
- `package.json` — залежності для створення Android/iOS оболонок;
- `PRIVACY-POLICY.md` — чернетка політики конфіденційності.

## Підготовка Android та iOS
Потрібні Node.js LTS, Android Studio для Android та macOS з Xcode для iOS.

```bash
npm install
npx cap add android
npx cap add ios
npx cap sync
npx cap open android
# або на Mac:
npx cap open ios
```

Для подальших змін у `www/` виконуйте `npx cap sync`, після чого збирайте застосунок в Android Studio або Xcode.

## Важливо перед публікацією
Цей архів — вихідний проєкт, а не готовий підписаний APK/AAB чи IPA. Для публікації потрібні перевірка на реальних пристроях, унікальний application ID / bundle ID, фінальна іконка, скриншоти, контакт розробника, актуальна політика конфіденційності та облікові записи Google Play Console / Apple Developer. У політиці конфіденційності замініть рядок про контакт на робочу адресу розробника.
