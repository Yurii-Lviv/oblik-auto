ВАЖЛИВО ПРО ФОРМУЛИ:
Логіка перенесена з наданої таблиці 123.xlsx:
- загальний пробіг = кінцевий одометр - початковий;
- місто = загальний пробіг * 60%;
- траса = загальний пробіг * 40%;
- базова витрата кожного виду = відповідний пробіг * норма / 100;
- місто коригується на +5%, траса на -15%;
- пальне всього = залишок перед виїздом + отримано;
- залишок = пальне всього - розрахункова витрата.

Значення 60/40, 10.8, +5/-15 та 121/180 є прикладами з таблиці, їх можна змінювати.
